# HuffZip

HuffZip is a Java-based lossless file compression and decompression tool using the Huffman Coding algorithm.

## Features

- Huffman-based compression
- Lossless decompression
- Byte-level file processing
- Custom `.huf` file format
- Compression statistics
- Unit tests using JUnit 5

## Tech Stack

- Java 23
- Maven
- JUnit 5
